# AI Chat Board

AI Chat Board is a full-stack web application built using Java Spring Boot, MySQL, HTML, CSS, and JavaScript. The application enables users to send messages, receive AI-style responses, and view previous chat history.

## Features

* Send and receive chat messages
* Store chat history in MySQL database
* REST API integration using Spring Boot
* Responsive frontend using HTML, CSS, and JavaScript
* Automatic loading of previous conversations
* Timestamp support for chat messages

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* HTML
* CSS
* JavaScript
* Maven

## API Endpoints

* POST /chat - Send a message
* GET /chat - Retrieve chat history
